# AI·OPS COCKPIT · 想法池

> 所有新想法先记录，不直接进入设计或代码。只有当前主线空闲时才集中评审。

初始化时没有需要从现有路线图重复搬运的未分流想法。已经形成的产品判断、发展阶段和暂缓事项以 [PRODUCT.md](PRODUCT.md) 为唯一事实源。

```markdown

- 一句话：它是什么、做什么？

- 最小形态：最简单可以是什么？
```

```markdown
## 个人全能 AI 助理（终极方向 / North Star）

- 一句话：AI·OPS COCKPIT 的长期形态可以演进为一个属于我自己的、本地优先的「个人全能 AI 助理」——一个入口，懂我，能调度所有 Agent，能动手操作我的电脑。
- 核心乐趣：不是再造一个 ChatGPT，而是造一个「我的」助理：记忆是我的、工具是我的机器、数据不出本机。
- 个人需求：工具越装越多、窗口越来越散，我想要的最终体验是「说一句话，它自己选 Agent、选工具、把事办完」。
- 最小形态：在现有群聊之上加三样东西——① 记忆层（个人档案 + 长期记忆，跨会话认识我）；② 路由层（单一入口自动派活给最合适的 Agent，而不是我手动勾选）；③ 执行层（Workspace 内真实完成任务并交付产物）。绘画等多模态想法属于后续能力扩展，服务于「全能」而非主线。
- 记录日期：2026-08-04
- 状态：inbox
```

```markdown
## 文字多 AI 绘画（绘画底座）

- 一句话：输入一段提示词，多个 AI 绘图引擎并行作画，结果同屏对比，直接挑图下载。
- 核心乐趣：把「调一个绘图接口」变成「绘图擂台」，谁画得好一目了然。
- 个人需求：柳总想用一段提示词让多个 AI 同时作画并直接对比效果；当前项目尚无任何绘画能力，需先建底座。
- 最小形态：前端输入提示词 → 后端并行调用绘图引擎（首选火山方舟 doubao-seedream-5.0-lite，可扩展其他引擎）→ 多图画布同屏展示 → 点击放大 / 下载。
- 记录日期：2026-08-04
- 状态：inbox
```

```markdown
## 图片多 AI 对比 · 提示词合成（柳总小功能）

- 一句话：上传一张参考图，多个视觉 AI 读图各自生成绘画提示词并合成「最好的提示词」；再用该提示词让多个 AI 实际作画，对比画出来的图选优，形成 图→提示词→图 闭环。
- 核心乐趣：一群 AI 看图打擂、优中选优；提示词好不好，直接用画作说话。
- 个人需求：柳总拿到参考图后想快速产出高质量绘画提示词并验证绘画效果，人工逐个模型试、再手动挑选太费时间。
- 最小形态：① 上传图片 → ② 多个视觉模型并行读图，各出一条提示词 → ③ 汇总模型合成最优提示词 → ④ 一键开画：多个绘图引擎按提示词 + 参考图（图生图）作画，同屏对比选优。
- 记录日期：2026-08-04
- 状态：inbox
```
